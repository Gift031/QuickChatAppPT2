# QuickChat (PROG5121 PoE)

Console Java Maven application implementing Part 1, Part 2 and Part 3 requirements.

## Run

```bash
mvn exec:java
```

## Test

```bash
mvn test
```

## Notes

- CI workflow: `.github/workflows/test-java.yml`
- Stored messages JSON file used by the app: `stored-messages.json`
- Target Java version: 17
